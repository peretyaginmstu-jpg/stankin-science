# Инструменты для выбора научной повестки

Репозитории и их документация проверены 3 октября 2026 года. Это подбор для сайта СТАНКИН; приведённые возможности не означают, что все библиотеки уже установлены.

| Инструмент | Задача сайта | Что требуется |
|---|---|---|
| [Apache ECharts](https://github.com/apache/echarts) | Внедрён: интерактивные координатные карты, годовая динамика СТАНКИН и переход от точки к публикациям | Официальная версия 6.1.0 хранится локально; Canvas, richText, резервные таблицы, лицензии и SHA-256 |
| [Cytoscape.js](https://github.com/cytoscape/cytoscape.js) | Сеть тем, статей, авторов и организаций с раскрытием узлов | Проверенные рёбра, объяснение значения и веса каждой связи; идентификаторы авторов |
| [bibliometrix](https://github.com/massimoaria/bibliometrix) | Научные тематические карты, эволюция тем, совместное цитирование, библиографическое сочетание | Отдельный этап анализа на R; ключевые слова, ссылки и библиографические метаданные. В Pages публикуются результаты расчёта |
| [BERTopic](https://github.com/MaartenGr/BERTopic) | Узкие подтемы внутри широких кластеров и их изменение со временем | Аннотации, сопоставимый мировой корпус, оценка покрытия текстами и ручная проверка названий кластеров |
| [NetworkX](https://github.com/networkx/networkx) | Группы научной сети, её связность и исследования, соединяющие группы | Реальные связи по ссылкам, соавторству или явно определённому сходству; проверка устойчивости к порогу связи |
| [Matplotlib](https://github.com/matplotlib/matplotlib) + [SciencePlots](https://github.com/garrettj403/SciencePlots) | Векторные научные рисунки, интервалы и схемы для совещания | Уже включены в публикацию; проверенный JSON, зафиксированные версии, SHA-256 исходных данных и рисунков |
| [Plotly.py](https://github.com/plotly/plotly.py), [Altair](https://github.com/vega/altair) | Альтернативная интерактивная визуализация непосредственно из Python | Выбрать один подход после прототипа, оценить размер автономной страницы и соответствие CSP; не подключать все графические движки одновременно |
| [D3 Sankey](https://github.com/d3/d3-sankey) | Потоки публикаций между согласованными уровнями классификации | Только измеренные потоки с правилами исключения двойного счёта. Не изображать предполагаемую кооперацию шириной потока |
| [Python Graph Gallery](https://github.com/holtzy/The-Python-Graph-Gallery) | Образцы композиции научных рисунков и исходный код | Выбирать форму по вопросу и данным; каталог примеров не является аналитической методикой |

## Порядок внедрения

1. ECharts внедрён для исследования имеющихся чисел в `#pish-explorer`. Python остаётся источником рисунков для печати и проверки.
2. Расширить публичный снимок ссылками, устойчивыми идентификаторами авторов и доступными аннотациями. В текущем компактном снимке есть заголовки, годы, основная тема и имена авторов; списков цитируемых работ и аннотаций нет. Кафедра автора из принадлежности к университету не выводится.
3. Рассчитать и проверить сеть средствами bibliometrix или NetworkX; выбрать один основной воспроизводимый конвейер. Отобразить её через Cytoscape.js.
4. Применить BERTopic к сопоставимым корпусам СТАНКИН и мира для проверки узких научных вопросов. Мировые тематические счётчики сами по себе не заменяют мировой корпус текстов.

## Границы выводов

Тематическая карта bibliometrix различает плотность связей внутри темы и её связи с остальной сетью. Низкие значения сами по себе не различают зарождающуюся и угасающую тему — нужна динамика. Центральность сети не равна научной важности, численности кафедры или инвестиционной привлекательности. Кластеры BERTopic — результат модели и выбора корпуса; они требуют проверки статей. Для ПИШ дополнительно нужны научная новизна, команда, эксперимент и промышленный заказчик.

Сетевые и текстовые инструменты пока не внедрены. ECharts использует существующие показатели и проверяемый перечень публикаций; он не добавляет измерений цитатной сети, кафедральных аффилиаций или автоматически найденных текстовых тем.
