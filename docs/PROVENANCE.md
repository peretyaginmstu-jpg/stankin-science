# Происхождение самостоятельного проекта

Исходники перенесены из публичного репозитория `peretyaginmstu-jpg/stankin-campus`, ветки `claude/admiring-ride-7cqv4h`, каталога `stankin-science/`.

Исходный коммит: `2759e8fdcc46fb1f8bb3f28730b158458f5badc2`. Сам репозиторий кампуса не изменялся. Вместе с проектом перенесены `.github/`, `.gitignore`, `.editorconfig`.

При подготовке публикации добавлены 188 идентификаторов исключений аффилиации по аудиту от 02.10.2026, исправлены правила тематических групп и границы неполных рейтингов. Полные приватные файлы аудита не перенесены. Ошибочная тематическая категория Military Technology не используется как основание исключения работы.

Публикация использует анонимный доступ OpenAlex по запросу владельца. Опциональный ключ поддерживается через GitHub Actions Secret; значение ключа не требуется для сборки и не хранится в исходниках. Ограничения доступа: https://help.openalex.org/api/authentication/.

`SITE.noindex = true` сохранён. Запрет индексации не является ограничением доступа: сайт и этот репозиторий публичны.
